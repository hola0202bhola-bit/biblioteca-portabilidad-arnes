# ADR 001: alcance local, memoria e instancia del arnés

Fecha: 24/11/2026. Decisión técnica de Codex para esta demostración autorizada; revisión del alumno pendiente.

Usar Express/TypeScript y las capas existentes para reutilizar el stack sin cambios. Un repositorio en memoria permite entregar un módulo completo pequeño y probar HTTP real sin tocar ninguna base. Las operaciones de consulta y escritura son síncronas dentro de un solo proceso; el test concurrente comprueba solo ese escenario.

Se conserva sin cambios el núcleo y los dos verificadores genéricos. Se crea una orquestación específica de biblioteca porque scripts/check.mjs y check-product.mjs originales contienen requisitos, suites, migraciones, fixtures y protecciones propias de Ecclesia. Es una limitación real de la generalización del arnés: no basta cambiar un nombre en PROYECTO.md para ejecutar el pipeline entero. Se documenta la adaptación en lugar de simular ese pipeline o eliminar reglas de su repositorio original.

Consecuencias: cero datos reales y ejecución breve, sin persistencia tras reinicio, sin autenticación, sin demostración de SQL, del hook de índice o de todas las pruebas del arnés original. Son exclusiones explícitas del ejemplo; no pruebas aprobadas.
